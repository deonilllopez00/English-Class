Teacher's Editing Guide

You can customize this portal by editing the JavaScript near the bottom of this file.

1. Change class information

Find the classes array in the JavaScript section. Edit the class name, instructor, day, subject, and time.

2. Add your real Zoom links

Replace https://zoom.us in each class's zoom field with the correct meeting URL.

3. Set the class date and time

Use the start and end fields in YYYY-MM-DDTHH:mm:ss format. These dates determine whether a class is Upcoming, Live Now, or Completed. Enter times in the browser's local time zone.

4. Publish your portal

Save the file as index.html. Open it in your browser to preview it, or upload it to a static web host to share it with your students.

Privacy tip: This is a front-end template. Anyone with access to the page can view its schedule and Zoom links. Do not put private student information or sensitive meeting details on a publicly accessible page.
